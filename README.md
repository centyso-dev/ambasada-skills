# Ambasada skills

Skills for Claude Code, Cursor and Codex, mirrored from the Ambasada devkit (`@ambasada/skills` on npm).

```sh
npx skills add centyso-dev/ambasada-skills
```

- `skills/ambasada-product`: build a digital product that sells in the Village (Next.js on Cloudflare, `ambasada dev`/`deploy`, sellable checklist).
- `skills/ambasada-payments`: add TON payments to any app for the Hack A Ton village.

Built by [CENTYSO](https://centyso.com) for [Ambasada](https://ambasada.id). MIT.
